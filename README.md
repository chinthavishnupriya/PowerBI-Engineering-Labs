# Power BI Engineering Labs

A collection of Power BI lab exercises covering data preparation, data modeling, and interactive report development.

## Exercise 1: Sales and Monthly Forecast Dashboard

**Power BI file:** [`PowerBI_Engineering_Lab_Exercise1.pbix`](./PowerBI_Engineering_Lab_Exercise1.pbix)

### Work completed
- Transformed monthly forecast data using Power Query.
- Created relationships between sales, product, customer, forecast, and date tables.
- Added report cards for Total Sales and Total Orders.
- Created visuals for total quantity, total forecast, sales by order date, forecast by month, and sales by product.
- Added a date slicer for interactive filtering.

### Open the report
1. Download the `.pbix` file from this repository.
2. Open it in Microsoft Power BI Desktop.
3. Explore the report visuals and use the date slicer to filter the data.
