# Power BI Engineering Labs

A hands-on portfolio covering Power Query ETL, dimensional modeling, DAX measures, executive report design, and Power BI deployment concepts.

## Repository structure

- **Exercise-01:** Power BI report, sales and forecast CSVs, CRM/product workbook, and Power Query M reference.
- **Exercise-02:** AdventureWorks report, DAX reference, and dimensional-model documentation.
- **Exercise-03:** AdventureWorks report and DAX measure library.
- **Exercise-04:** Executive report, report blueprint, and Power BI theme.
- **Exercise-05:** Capstone implementation notes and example RLS expression.

## How to use this repository

1. Open the relevant PBIX file in Power BI Desktop.
2. Read the exercise README for its objective, model context, and report description.
3. Treat Markdown, DAX, and JSON files as references that may need adapting to the model and environment.
4. Keep credentials, access tokens, gateway secrets, and private customer data out of the repository.

## Technology

- Power BI Desktop and Power Query M
- SQL Server / SSMS and AdventureWorks DW
- Dimensional modeling and relationship design
- DAX measures and time intelligence
- Interactive reports, drill-through, and tooltips
- Power BI Service concepts: refresh, gateway, app deployment, and row-level security
